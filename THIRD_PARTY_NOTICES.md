# Third-party notices

FeastCloud depends only on software whose licenses permit commercial use, modification, redistribution, and self-hosting. Exact dependency versions and integrity hashes are locked in `package-lock.json`, `services/core/go.sum`, and `services/edge/go.sum`; complete license texts remain in each downloaded package and source distribution.

The release checks fail closed when a new npm license expression or compiled Go module has not been reviewed. The current JavaScript graph includes permissive licenses plus MPL-2.0 for the exact Lightning CSS 1.33.0 build-tool family. Its non-distributed boundary and version guard are recorded in [`docs/governance/license-reviews/MPL-2.0-lightningcss-1.33.0.md`](docs/governance/license-reviews/MPL-2.0-lightningcss-1.33.0.md).

The web client self-hosts Poppins through `@fontsource/poppins`. Poppins is distributed under the SIL Open Font License 1.1; the package includes the license text and the release SBOM records the exact version. The application does not require Google Fonts or another proprietary font service at runtime.

The primary local database profile installs PostgreSQL 17.10 through the open-source Homebrew formula and runs a workspace-local cluster without a global service. PostgreSQL uses the PostgreSQL License; Homebrew formula dependencies use their respective open-source licenses. CI optionally uses the Docker Official Image packaging on Alpine Linux; local development does not require Docker. Release infrastructure scans/SBOMs must include exact resolved package versions or image digests before distribution.
