# Phase 0 design-partner kit

Use this kit with one multi-brand cloud kitchen, one QSR, and one dine-in restaurant before treating product assumptions as validated. It does not replace legal, food-safety, tax, labor, or privacy advice.

- `workflow-observation.md` captures how work actually moves through an outlet, including manual failure paths.
- `baseline-metrics.md` defines the pilot baseline and measurement method.
- `data-readiness.md` is the technical and governance checklist required before importing live data.

Completed partner records contain confidential information and must not be committed to this public repository.
